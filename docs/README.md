# geometric_lib

## Общее описание

geometric_lib — библиотека на Python для вычисления характеристик
геометрических фигур: круга, квадрата, прямоугольника и трапеции.

Для работы требуется Python 3. Внешние библиотеки устанавливать
не нужно. Модуль circle использует стандартный модуль math.

Файлы проекта:

- circle.py — площадь круга и длина окружности;
- square.py — площадь и периметр квадрата;
- rectangle.py — проверка равенства сторон, площадь, периметр и диагональ прямоугольника;
- trapezoid.py — площадь, средняя линия и периметр трапеции;
- docs/README.md — документация проекта.

Размеры фигур передаются в одинаковых единицах измерения.
Площади возвращаются в квадратных единицах, длины — в исходных.
Функции не проверяют корректность размеров, поэтому следует
передавать положительные значения и допустимые размеры фигур.

## Описание функций и примеры вызова

Примеры можно выполнить в Python, запущенном из каталога проекта.

### Модуль circle

#### area(r)

Вычисляет площадь круга по формуле S = πr².

Параметры:
- `r` — радиус круга.

```python
import circle

print(circle.area(2))
# Приблизительно 12.566370614359172
```

#### perimeter(r)

Вычисляет длину окружности по формуле P = 2πr.

Параметры:
- `r` — радиус круга.

```python
import circle

print(circle.perimeter(2))
# Приблизительно 12.566370614359172
```

### Модуль square

#### area(a)

Вычисляет площадь квадрата по формуле S = a².

Параметры:
- `a` — длина стороны квадрата.

```python
import square

print(square.area(3))
# 9
```

#### perimeter(a)

Вычисляет периметр квадрата по формуле P = 4a.

Параметры:
- `a` — длина стороны квадрата.

```python
import square

print(square.perimeter(3))
# 12
```

### Модуль rectangle

#### is_square(a, b)

Проверяет равенство сторон a и b.
Возвращает True, если стороны равны, иначе False.

Параметры:
- `a` — длина первой стороны прямоугольника.
- `b` — длина второй стороны прямоугольника.

```python
import rectangle

print(rectangle.is_square(3, 3))
# True

print(rectangle.is_square(3, 4))
# False
```

#### area(a, b)

Вычисляет площадь прямоугольника по формуле S = ab.

Параметры:
- `a` — длина первой стороны прямоугольника.
- `b` — длина второй стороны прямоугольника.

```python
import rectangle

print(rectangle.area(3, 4))
# 12
```

#### perimeter(a, b)

Вычисляет периметр прямоугольника по формуле P = 2a + 2b.

Параметры:
- `a` — длина первой стороны прямоугольника.
- `b` — длина второй стороны прямоугольника.

```python
import rectangle

print(rectangle.perimeter(3, 4))
# 14
```

#### diagonal(a, b)

Вычисляет длину диагонали прямоугольника
по формуле d = √(a² + b²).

Параметры:
- `a` — длина первой стороны прямоугольника.
- `b` — длина второй стороны прямоугольника.

```python
import rectangle

print(rectangle.diagonal(3, 4))
# 5.0
```

### Модуль trapezoid

#### area(a, b, h)

Вычисляет площадь трапеции по формуле S = (a + b)h / 2.

Параметры:
- `a` — длина первого основания трапеции.
- `b` — длина второго основания трапеции.
- `h` — высота трапеции.

```python
import trapezoid

print(trapezoid.area(3, 5, 4))
# 16.0
```

#### midline(a, b)

Вычисляет длину средней линии трапеции
по формуле m = (a + b) / 2.

Параметры:
- `a` — длина первого основания трапеции.
- `b` — длина второго основания трапеции.

```python
import trapezoid

print(trapezoid.midline(3, 5))
# 4.0
```

#### perimeter(a, b, c, d)

Вычисляет периметр трапеции по формуле P = a + b + c + d.

Параметры:
- `a` — длина первого основания трапеции.
- `b` — длина второго основания трапеции.
- `c` — длина первой боковой стороны трапеции.
- `d` — длина второй боковой стороны трапеции.

```python
import trapezoid

print(trapezoid.perimeter(3, 5, 4, 4))
# 16
```
